# Inventory and Warehouse Management System

## Project Description
This project is developed to manage products, warehouses, and stock details. It helps users maintain inventory records and manage purchase and sales orders.

## Technologies Used
- Python
- SQLite3
- FastAPI
- SQL

## Features
- Add new products.
- View product details.
- Update product information.
- Delete product records.
- Manage warehouse details.
- Track stock availability.
- Manage purchase and sales orders.

## Project Operations
Implemented CRUD operations:
- Create – Add new records.
- Read – View existing records.
- Update – Modify existing records.
- Delete – Remove records.

## Installation

1. Clone the repository.
2. Install the required packages:
   `pip install fastapi uvicorn`
3. Run the application:
   `uvicorn main:app --reload`
4. Open the API documentation in your browser:
   `http://127.0.0.1:8000/docs`

## Conclusion
This project helps manage inventory information efficiently using Python, SQLite3, and FastAPI.
